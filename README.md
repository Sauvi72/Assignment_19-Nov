## What this project does

This is a job listing app made in React. You can see all jobs, filter them by work mode, apply to jobs, and see your applied jobs. Max 3 applications allowed.

## Pages

- `/` - Home page with total, applied and remote job count
- `/jobs` - All jobs with mode filter dropdown
- `/jobs/:id` - Details of a single job
- `/applied` - Shows jobs you applied to
